---
title: Painel de pessoas
---

O painel de pessoas serve para localizar cadastros, criar uma pessoa e manter informações que pertencem ao Event Manager.

Permissões administrativas são gerenciadas em uma área própria.

## Busca

Pesquise por nome, e-mail, telefone ou documento.

A lista só representa o recorte carregado. Antes de criar uma nova pessoa, tente variações do identificador para reduzir duplicidades.

Use o filtro de perfil de ministrante quando a busca tiver essa finalidade.

## Cadastro

Uma pessoa sem conta vinculada pode ter seus dados cadastrais mantidos no Event Manager.

Quando o perfil é administrado externamente, nome, e-mail principal, telefone, documento e matrícula aparecem como somente leitura. Corrija esses dados no Keycloak ou no Account Manager para preservar a consistência entre sistemas.

E-mails secundários e informações internas continuam sujeitos às regras exibidas no painel.

## Usuário vinculado

A seção de usuário é informativa.

Ela ajuda a confirmar qual conta está associada à pessoa. Não altere identidade ou acesso do Keycloak a partir desse cadastro.

Uma pessoa pode existir sem usuário. Isso não impede sua participação em cadastros do evento nem a preparação de um cargo administrativo. O cargo só produzirá acesso depois que a conta for vinculada.

## Perfil de ministrante

O perfil de ministrante é global para aquela pessoa, isto é, será compartilhado entre todos os eventos do sistema.

Ele não substitui o cadastro da pessoa no evento.

Crie-o quando for necessário publicar biografia, foto ou contatos.

Trate e-mail, WhatsApp, fotografia e biografia como dados públicos quando a opção de publicação for usada. Obtenha o consentimento da pessoa antes de divulgar informações pessoais.

## Vínculos e histórico

Pessoas autorizadas podem consultar o histórico do cadastro. A visão de vínculos, quando disponível, é uma ferramenta de diagnóstico e deve ser usada com cuidado porque reúne relações com outros dados do sistema.

Para possíveis duplicidades, use o fluxo específico de mesclagem em vez de editar identificadores até que dois registros pareçam iguais.
