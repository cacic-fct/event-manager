---
title: Carteira
---

A carteira reúne cartões que a pessoa pode apresentar no celular ou preparar para uso sem conexão.

Os cartões disponíveis dependem dos dados da conta e do que foi configurado neste navegador.

## Cartão CACiC Eventos

O cartão principal identifica a pessoa no Event Manager e exibe o código usado pelos coletores de presença.

Quando a leitura falhar, a organização pode localizar a pessoa por um identificador e registrar a presença manualmente.

## Código off-line

O cartão **Código off-line** mostra um código temporário associado à conta do e-mail exibido.

Abra a carteira uma vez com internet e login para preparar esse cartão no dispositivo. Depois disso, ele pode continuar disponível, mesmo em uma interrupção de rede.

O código muda com o tempo. Apresente o valor somente quando a organização solicitar.

## Registro Acadêmico

O cartão de registro acadêmico aparece automaticamente para contas de graduação que possuem matrícula disponível.

Os dados vêm da conta. Quando estiverem incorretos, use o Account Manager para corrigi-los.

## Cartão do R.U.

Em **Adicionar cartão**, informe o número de cliente usado no Restaurante Universitário.

Esse número é salvo localmente neste navegador. Ele não é sincronizado para outros dispositivos.

Ao trocar de celular, limpar os dados do site ou usar outro perfil do navegador, adicione o cartão novamente.

## Impressão

Use **Imprimir crachá** e confira a pré-visualização antes de imprimir.

A impressão é uma alternativa para quem não poderá apresentar o celular, mas não altera a conta nem cria uma credencial diferente.

## Disponibilidade off-line

O indicador de nuvem informa se o suporte geral a recursos off-line está instalado. Ele não garante, sozinho, que todos os cartões já foram preparados.

Abra a carteira com internet antes do evento e confirme que os cartões necessários aparecem.
