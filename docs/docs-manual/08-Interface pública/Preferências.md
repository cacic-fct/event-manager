---
title: Preferências
---

A área de preferências reúne ajustes locais do aplicativo e atalhos da conta.

## Visualização do calendário

A visualização padrão define como os itens do calendário abrem neste dispositivo.

Essa escolha é local. Alterá-la em um navegador não muda os demais dispositivos da pessoa.

## Feed privado

A pessoa autenticada pode ativar um feed com sua programação para aplicativos de calendário.

O link é privado. Quem possui a URL pode consultar o conteúdo disponibilizado pelo feed sem repetir o login.

Não publique o link nem o envie para terceiros.

É possível copiar, baixar ou adicionar o feed a um aplicativo compatível. Novas inscrições aparecem quando o aplicativo de calendário atualizar a assinatura.

## Rotacionar a chave

Rotacione a chave quando o link tiver sido exposto ou quando for necessário retirar o acesso de uma assinatura antiga.

O link anterior deixa de ser a referência válida. Atualize os aplicativos de calendário que devem continuar recebendo a programação.

Um feed pode ser desativado automaticamente após um longo período sem login. Ao reativar, decida se o link antigo pode ser mantido ou se deve ser substituído.

## Service Worker

O Service Worker habilita cache do aplicativo, navegação off-line e notificações push.

Use **Estado**, **Atualizar** e **Cancelar registro** somente para diagnóstico ou quando o suporte orientar. Cancelar o registro pode exigir novo download de arquivos e não apaga, por si só, todos os dados locais da pessoa.

## Conta

Dados principais da conta são editados no Account Manager.
